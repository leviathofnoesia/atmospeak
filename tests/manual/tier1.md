# Tier 1 Manual AcceptanceUse this script after the automated gates pass.## T1-01 AI Auto-Edit1. Start a local Ollama-compatible chat endpoint and make sure the configured model is available.2. Start Atmospeak with `bun run tauri dev`.3. Open Settings, set AI edit Provider to Local Ollama, Style to Concise, Endpoint to `http://127.0.0.1:11434/api/chat`, and save.4. Create a transcript and confirm it appears in Latest transcript and History.5. Click Edit last on Home and confirm the transcript text updates in Home and History.6. Create another transcript, expand it in History, click the sparkles action, and confirm the saved row updates.7. Enable Auto-edit before paste, save, dictate into Notepad, and confirm the pasted text and saved History row use the polished text.8. Optional remote smoke: set `WIND_SPEAK_POLISH_API_KEY` before launch, switch Provider to OpenAI-compatible, configure endpoint/model, and repeat one explicit edit.9. Confirm feedback reports and saved settings do not contain an API key.## T1-02 Language Picker And Auto-Detect1. Start Atmospeak with `bun run tauri dev`.2. Open Settings.3. Set Recognition language to English and save.4. Dictate an English phrase into Notepad and confirm it transcribes normally.5. Set Recognition language to Auto-detect and save.6. If `src-tauri/resources/models/ggml-base.bin` or another multilingual model is installed and selected, dictate a non-English phrase and confirm the language is recognized.7. If only `ggml-base.en.bin` is installed, confirm the model inventory shows Base Multilingual as not installed and keep this T1-02 item open.## T1-11 Privacy Mode And Auto-Delete1. Start Atmospeak with `bun run tauri dev`.2. Open Home.3. Enable Privacy mode and confirm the notice says privacy mode is enabled.4. Set Auto-delete transcripts to After 15 minutes.5. Save or navigate away and back; confirm the setting remains.6. Create a transcript and confirm it still appears in History before the retention window expires.7. For a fast local smoke, use a test profile with an old `transcript_sessions.created_at` row and restart the app.8. Confirm the old transcript row is removed and the runtime event log records an auto-delete privacy sweep.## T1-08 Real Frequency Meter1. Start Atmospeak with `bun run tauri dev`.2. Show the floating control.3. Start dictation and hum or speak with a low voice.4. Confirm the lower bands of the floating meter move more than the high bands.5. Speak with sharper consonants or play a high-frequency tone near the microphone.6. Confirm the higher bands respond independently instead of all bars following the same envelope.7. Confirm meter updates remain smooth while live transcript preview is active.## T1-06 Voice-Trigger Snippet Expansion1. Open Snippets.2. Add an enabled snippet with trigger `ship intro` and body `Thanks for the review.`3. Open Settings and confirm live preview is enabled.4. Start dictation and say `ship intro after standup`.5. Confirm the floating live preview shows `Thanks for the review. after standup` before final paste.6. Disable final accuracy pass and repeat the dictation.7. Confirm the final transcript does not duplicate the snippet body or re-expand the trigger.## T2-08 In-App Feedback And Crash Report1. Open Settings.2. Enter a feedback message and leave Feedback webhook URL empty.3. Click Send feedback.4. Confirm Atmospeak reports that the feedback file was saved locally.5. Open the saved JSON report from the notice/log location and confirm it includes recent runtime events and sanitized settings.6. Confirm local paths, advanced runtime paths, microphone names, and the webhook URL are not present in the report.7. Configure a test webhook URL, save settings, send feedback again, and confirm the webhook receives the JSON payload.
