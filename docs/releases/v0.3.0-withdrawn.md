# Atmospeak 0.3.0 withdrawal record

Atmospeak 0.3.0 was published on 2026-07-26 and withdrawn the same day because
its first-run state migration, microphone validation, native overlay
performance, dragging, and hub fidelity did not meet the release criteria.

The source remains preserved in git at merge commit `bb31a67`. The public
release and `v0.3.0` tag were removed so the updater and website cannot continue
offering the defective build.
