# Atmospeak v0.5.0

Atmospeak 0.5.0 moves long-form dictation from whole-recording batch
transcription to a fully local streaming pipeline.

## Highlights

- Transcribes bounded speech segments while recording and reconciles only the
  remaining tail after stop.
- Shows live partial and stable text inside the Atmospeak dock, then pastes one
  final result into the original target.
- Adds crash-isolated Vulkan and CPU Whisper sidecars with automatic local
  fallback to the resident host and one-shot CLI.
- Uses local Silero VAD to finalize pauses and force-split continuous speech
  without sending audio or text to a cloud service.
- Adds Automatic Balanced model selection based on measured local performance;
  only already-installed models are considered.
- Makes Hold and Tap shortcuts reliable: releasing any required Hold key stops
  immediately, and a second Tap press stops without release polling.
- Adds bounded, sanitized shortcut diagnostics and local streaming performance
  metrics.

## Reliability

This release also fixes duplicate paste, stale ASR warmups, overlapping ASR
sessions, unbounded sidecar audio growth, rolling-preview duplication, fallback
audio loss under queue pressure, and several failure paths that could leave the
engine stuck in Processing.
