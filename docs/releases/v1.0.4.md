# Atmospeak Free 1.0.4

Atmospeak Free now bundles Parakeet Unified English 0.6B. It transcribes English offline on the CPU and shows a live preview as you speak. Settings shows the model size and Handy's reference accuracy and speed benchmarks.

- History saves audio before paste. It can recover interrupted recordings and replay the saved audio when streaming misses part of a dictation.
- You can compare and copy transcript versions, set cleanup preferences per app, and edit selected text by voice.
- Paste respects newer clipboard contents. Settings lets you show the floating control only while recording.

Download the setup EXE for a normal Windows 10 or 11 x64 install. An MSI and a portable ZIP are available on the same release. Compare your download with `SHA256SUMS.txt` before you run it.

The bundled Parakeet weights use about 697 MiB of disk space and need no download after installation.
