# Atmospeak v1.0.2

Patch release for release→paste latency when the orb already showed the words,
plus polish endpoint / inject hardening that was in flight with that fix.

## Fixes

- **Preview paste without coverage stall.** Trailing silence after the last
  spoken word inflated wall-clock `durationMs` past ASR `covered_through_ms`,
  so the coverage gate rejected a ready hypothesis and forced Final — often a
  multi-second host batch (`session is not active` fallback). Release now
  pastes any non-empty live preview for the active session immediately.
  Material streaming frame drops still force Final.

## Changed

- Polish endpoints validated (Ollama loopback-only; OpenAI-compatible HTTPS).
- Polish API keys bound to endpoint origin with rebinding confirmation.
- Remote OpenAI-compatible auto-polish does not auto-inject polished text;
  history paste of AI-edited text asks for confirmation.
- Inject surface narrowed to `inject_session` / `inject_onboarding_sample`.
- Llama host / polish runtime and Advanced polish settings updates.

## Measured (preview paste)

| Path | Before (coverage fail) | After |
| --- | ---: | ---: |
| Stage `totalMs` | ~29 000 (host) | **~20–26** |
| `asr` / `finalize_ms` | ~28 000 | **0** |
| Inject | ~20–100 ms | ~18–23 ms |

## Upgrade

Install over 1.0.1. No migration. Settings gain `polishApiKeyOrigin` (default
empty). History and dictionary are unchanged.
