# Atmospeak v1.0.2

Patch release: release→paste latency fix plus deepsec hardening.

## Fixes

- **Preview paste without coverage stall.** Trailing silence after the last
  spoken word inflated wall-clock `durationMs` past ASR `covered_through_ms`,
  so the coverage gate rejected a ready hypothesis and forced Final — often a
  multi-second host batch. Release now pastes any non-empty live preview for
  the active session immediately. Material streaming frame drops still force
  Final.

## Security (deepsec workstreams)

1. **Paste IPC** — `inject_session` / `inject_onboarding_sample` replace
   freeform `inject_text`. History pastes cleaned text by default; polished
   paste requires confirm. Control chars stripped at the inject sink. Remote
   OpenAI-compatible auto-polish no longer auto-injects.
2. **Llama zip** — Pinned SHA-256 for the zip and `llama-server.exe`;
   downloads use `write_verified_stream`; bootstrap verifies the same hashes.
3. **Polish secrets** — Ollama loopback-only; OpenAI-compatible requires
   HTTPS; API keys bound to endpoint origin with reconfirm on change.
4. **ASR override** — Overrides ignored/cleared in release; debug builds
   require absolute trusted paths under resource/app-data; override UI hidden
   in prod.
5. **Pages CI** — Job-scoped permissions; actions pinned to commit SHAs.
