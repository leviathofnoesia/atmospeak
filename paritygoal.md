# Atmospeak Feature Parity — Master Plan## GoalAchieve **functional parity with Wispr Flow and BridgeVoice**, then layer Atmospeak's own novel features on top. Clone their feature surfaces, not their branding.**Success criteria:** A user moving from either app to Atmospeak loses zero core capability, and gains at least one atmospeak-only differentiator.---## 1. Acceptance / Definition of DoneFor every tier, ship is gated on:1. **All tier-N unit tests pass** (Rust + Vitest)2. **Manual acceptance script** in `tests/manual/<tier>.md` passes3. **No regression** in existing Tauri command contract (`get_app_snapshot` shape stable)4. **Docs updated**: `README.md`, `CHANGELOG.md`, `docs/RELEASE.md`5. **Performance**: median transcription < 1.5× audio duration; live preview latency < 800ms6. **Privacy**: no audio leaves the machine unless user opts into cloud provider---## 6. Risks & Open Questions| Risk | Mitigation ||---|---|| LLM polish latency adds 1–3s to the dictation loop | Make it opt-in (`autoPolish: false` default). Show in overlay only after final paste. || Whisper multilingual model 5× larger | Download-on-demand, not bundled by default. Keep `base.en` bundled. || IDE accessibility tree access requires UAC/admin on Windows | Document; require user to grant. Same as Wispr. || Cloud provider key leakage | Use OS keyring (`keyring` crate). Never write to SQLite. || Cross-device sync scope creep | Defer to T2-02. Start with export/import JSON as a poor-man's sync. || Linux `SendInput` is platform-incompatible | Gate Linux injection behind `xdotool`/`wl-copy` feature flag in `Cargo.toml`. |---## 7.
