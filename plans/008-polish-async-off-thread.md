During this time, the overlay frequency meter stops updating, shortcut events queue up, and the UI appears frozen. The `polish_session` command additionally acquires the database lock (`state.database.lock()`) before spawning the blocking call, preventing all other database operations (recording state, settings, etc.) during the entire polish duration. Moving the blocking HTTP call to a background thread and releasing the database lock during the network call fixes both problems.## Current state- `src-tauri/src/commands.rs:46-53` — `polish_transcript`:  ```rust  #[tauri::command]  pub fn polish_transcript(      state: State<'_, AppState>,      text: String,      style: Option<PolishStyle>,  ) -> CommandResult<PolishResult> {      let settings = to_command_result(state.database.lock().load_settings())?;
