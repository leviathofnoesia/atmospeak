Consumers need 10+ fields (the data plane: app dir, shortcut test flag, last external target window, runtime event log, retention sweeper cancel). This PR completes the struct and adds the first named accessors as a seam.### What changes**`src-tauri/src/services/app_state.rs`**: 4 fields → 10 fields, with named accessors.New fields:- `app_dir: PathBuf` — used by diagnostics and streaming for absolute paths- `shortcut_test_active: Arc<Mutex<bool>>` — set while the user is running the "press your shortcut" test- `last_external_target_window: Arc<Mutex<Option<isize>>>` — last HWND we pasted into, so we can restore focus- `runtime_events: Arc<Mutex<Vec<RuntimeEvent>>>` — bounded log (200 entries, newest first)- `retention_sweeper_cancel: Arc<AtomicBool>` — signal the background sweeper to exit cleanlyNew named accessors (the seam):- `shortcuts_paused()` / `set_shortcuts_paused(b)`- `shortcut_test_active()` / `set_shortcut_test_active(b)`- `last_target_window()` / `set_last_target_window(t)`- `record_event(e)` / `recent_events(limit)` — bounded log- `cancel_retention_sweeper()`Existing fields stay `pub` so direct access still works.**`src-tauri/src/models.rs`**: add `RuntimeEvent` (chrono's `DateTime<Utc>` + `kind` + `message`).### Verification- `cargo check --manifest-path src-tauri/Cargo.toml`: exit 0- `cargo test --manifest-path src-tauri/Cargo.toml --lib`: 15 passed, 0 failed  - including the new `named_accessors_round_trip_state` test that exercises every new accessor### Out of scope (deferred to follow-up work)- The `injection` module still doesn't have a typed `InjectionTarget` value.
