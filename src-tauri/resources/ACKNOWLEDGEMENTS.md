# Wind Speak Runtime Acknowledgements

Wind Speak bundles the CPU Windows build of `whisper.cpp` and the English base
GGML model for a zero-setup local dictation prototype.

- `whisper.cpp`: https://github.com/ggml-org/whisper.cpp
- `ggml-base.en.bin`: https://huggingface.co/ggerganov/whisper.cpp

The runtime and model remain local to the installed application. Replace or add
models through Advanced settings or future in-app model packs.
